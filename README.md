# ScreenTyper — 螢幕辨識自動打字

[English README](README.en.md) · 英文介面：執行 `Launch ScreenTyper (English).bat` 或 `python -m screen_typer --english`。

框一塊螢幕 → OCR 認出上面的字 → 用模擬鍵盤照著打出來，速度和正確率都可以調成像真人在打。

需要 Windows 10/11、Python、Pillow，以及欲辨識語言的 Windows OCR 語言包。OCR 使用 Windows 內建引擎，鍵盤使用 Windows 的 `SendInput`。

```powershell
python -m pip install -r requirements.txt
```

---

## 怎麼跑

雙擊此資料夾的 **`啟動.bat`**（中文介面）或 **`Launch ScreenTyper (English).bat`**（英文介面），也可以執行：

```bash
python -m screen_typer
# 英文介面：python -m screen_typer --english
```

## 三個步驟

| 步驟 | 按鈕 / 熱鍵 | 做什麼 |
| --- | --- | --- |
| ① | **選取區域** `F9` | 全螢幕變暗，拖曳框出要辨識的地方（支援多螢幕，Esc 取消） |
| ② | **辨識** `F10` | 認出文字，顯示在下方文字框，**可以直接編輯** |
| ③ | **開始打字** `F11` | 倒數幾秒讓你切到目標視窗，然後開始打 |
| — | **停止** `Esc` | 隨時中止，全域有效（不用切回本程式） |

文字框裡**灰色的那段是判斷你已經打過的，不會打出去**；黑色的才會。

## 用在會捲動的打字測驗

測驗畫面會隨著你打字往上捲，打完的行變灰，游標（藍色反白）跳到下一個字。
程式就是靠那個反白決定要從哪裡開始打。

1. 框選時**把游標那一行和下面幾行都框進去**（框太小會一直重抓）
2. 這幾個選項預設就是開的：從游標反白處開始打、不打最後一個未完成的字、換行併成空格
3. 勾 **自動監看** — 它每隔幾秒重新定位游標，只打還沒打的部分

「換行併成空格」很重要：測驗題目是連續文字，照著換行按 Enter 會把測驗打壞。

## 設定

| 設定 | 說明 |
| --- | --- |
| **速度 WPM** | **含所有停頓的實際平均速度**（5 字元 = 1 word）。設 150 打完就真的是 150。 |
| **正確率 %** | 最後留在畫面上的正確率。95% = 每 100 個字剛好錯 5 個（打成鍵盤上的鄰近鍵，不修正）。 |
| **節奏隨機度** | 每一鍵間隔的散亂程度。0 = 機器人等速，0.35 = 一般人。 |
| **手誤後自己退格改掉的機率** | 打錯 → 停一下 → 退格 → 改正。最終文字仍正確，只是過程更像人。 |
| **開始前等待** | 按下開始後倒數幾秒，讓你切到目標視窗。 |
| **放大倍率 / 高對比** | 小字調高倍率；深色底或淡字勾高對比。 |
| **還原反白選取的字** | 把選取／游標的彩色色塊還原成一般深字淺底，不然那個字會認錯。 |

速度上限約 **545 WPM**（每個按鍵送進系統本身要時間），超過會在狀態列提醒。

### 節奏是怎麼做的

不是固定間隔加亂數：對數常態抖動（人的按鍵間隔是右偏分布）、緩慢的速度漂移
（會忽快忽慢）、字元難度（空白較快，數字和大寫較慢，連續同字較快）、
標點與換行停頓、偶爾插入 0.35~1.6 秒「想一下」，最後整串等比例縮放，
讓含停頓的平均速度剛好等於設定的 WPM。

## 已知限制

- **反白還原偶爾會誤判**：深色介面上的白色卡片可能被當成選取色塊重畫
  （88 張裡有 1 張因此掉 0.05）。辨識結果怪怪的就把「還原反白選取的字」取消勾選。
- **OCR 品質就是 Windows 引擎的水準**。小字把放大倍率開到 2~3 倍；
  辨識完的文字可以直接在框裡改再按 F11。
- **語言包**：下拉選單只列出系統裝了 OCR 的語言。要加語言到
  「設定 → 時間與語言 → 語言與地區 → 語言選項 → 光學字元辨識」。
- **打字會送到最前面的視窗**，不是特定程式。倒數那幾秒要把游標點到目標位置。
- 少數用 DirectInput 的全螢幕遊戲會忽略 `SendInput`。一般應用程式、瀏覽器、編輯器都沒問題。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `screen_typer/app.py` | 介面、熱鍵、自動監看 |
| `screen_typer/ocr.py` | 螢幕擷取、游標定位、OCR 結果組字 |
| `screen_typer/highlight.py` | 反白色塊偵測與還原（靠結構特徵，不是顏色） |
| `screen_typer/win_ocr.ps1` | 呼叫 Windows 內建 OCR（純 ASCII，PowerShell 5.1 才不會讀成亂碼） |
| `screen_typer/keyboard.py` | SendInput 鍵盤模擬 + 節奏模型 |
| `screen_typer/region.py` | 全螢幕框選 |
| `captures/` | 執行時產生的原始擷取（只留最近 20 張）；不會上傳到公開儲存庫 |
| `dev/` | 原資料夾的測試樣本與評測檔；公開版本不包含 |

設定存在 `~/.screen_typer.json`（語言、速度、正確率、各選項、上次框的區域）。
